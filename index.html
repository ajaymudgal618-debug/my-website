    RJIT College RAG Chatbot

    A production chatbot for the college website that answers only from retrieved site content, using a hybrid of keyword and semantic search.

    How a question is answered

    1. College websiteRJIT site content
    2. Hybrid retrieverBM25 keyword + FAISS semantic search (all-MiniLM-L6-v2)
    3. LangGraph agentSelectable Groq models, summarized memory
    4. Grounded answerOnly from retrieved website content
    • FastAPI backend and Streamlit frontend, deployed live on Render.
    • Hybrid retrieval gives more accurate context than BM25 or FAISS alone.
    • LangChain and LangGraph's InMemorySaver keep multi-turn memory across model switches. Summarization middleware keeps long conversations within token limits.

    Chatbot with Tools

    An agentic chatbot that decides when to search the web, Wikipedia or arXiv, and remembers the conversation.

    • Built on LangChain and LangGraph's ReAct agent with a Groq-hosted gpt-oss-20b model that reasons about when to call external tools.
    • DuckDuckGo, Wikipedia and arXiv tools bring in real-time information. InMemorySaver persists conversation memory across sessions, and the UI is built with Streamlit.
